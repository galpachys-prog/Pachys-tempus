מוניטור סימולציה לאימוני ALS — עובד גם ללא רשת

מוניטורלטאבלט — מה שהחניכים רואים עמדת מדריךלאייפון — שליטה במדדים מכשיר יחידמוניטור + פאנל מדריך באותו מכשיר
בודק זמינות לא-מקוונת…
הכנה לעבודה בשטח (פעם אחת, עם אינטרנט)
  1. פתח את הכתובת הזו ב-Safari בטאבלט ובאייפון, וחכה להודעה הירוקה “מוכן לעבודה ללא רשת”.
  2. בכל מכשיר: כפתור שיתוף ← הוסף למסך הבית. מעכשיו פתח רק מהאייקון.
  3. פתח פעם אחת את “מוניטור” בטאבלט ואת “עמדת מדריך” באייפון ואשר הרשאת מצלמה.
בשטח — ללא קליטה
  1. חיבור בין המכשירים: הפעל נקודה חמה (Personal Hotspot) באחד המכשירים וחבר אליה את השני, או השתמש בכל ראוטר Wi-Fi נייד. אין צורך באינטרנט — רק רשת מקומית משותפת.
  2. בטאבלט: Menu ← Pair instructor — יוצג קוד QR.
  3. באייפון: סרוק קוד מוניטור ← יוצג קוד תשובה; הצג אותו למצלמת הטאבלט. המכשירים מתחברים ישירות זה לזה.
  4. אין רשת בכלל? בחר “מכשיר יחיד”: לחיצה ארוכה על הלוגו בפינת המוניטור פותחת את פאנל המדריך. באייפד אפשר גם Split View — מוניטור בחלון אחד ועמדת מדריך בחלון שני, והם מתחברים אוטומטית.

אם החיבור נקטע (מסך כבוי, מעבר רשת) — מבצעים שוב את הסריקה. המוניטור שומר את המדדים האחרונים.
